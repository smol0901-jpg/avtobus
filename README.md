# Рейзино Транзит — PWA-расписание автобусов

Офлайн-приложение: Большое Рейзино ↔ Красноармейский пр-т / ул. Нестерова (Гатчина).

## Запуск на GitHub Pages
1. Создайте репозиторий и загрузите содержимое папки в корень (включая `.nojekyll`).
2. Settings → Pages → Branch: `main`, папка `/ (root)`.
3. Откройте `https://<логин>.github.io/<репозиторий>/` и установите приложение («Добавить на главный экран»).

## Обновление версии
Измените `VERSION` в `js/data.js` и `V` в `sw.js` на одно значение — после пуша пользователи нажмут «Обновить приложение» в профиле.

## Данные
Расписание лежит в `js/data.js` (компактный формат). Свои маршруты добавляются во вкладке «Маршруты», резервная копия — «Экспорт/Импорт JSON».
Яндекс.Расписания не отдаёт данные браузеру напрямую (нужен API-ключ, нет CORS), поэтому данные вносятся вручную или через JSON.
