# Шаблоны JSON для загрузки расписаний

Файлы из этой папки можно импортировать прямо в приложении:
вкладка **«Профиль» → «Импорт JSON»** (или кнопка «Шаблоны» во вкладке «Маршруты»).

## Формат файла

```json
{
  "app": "reyzino-transit",
  "kind": "routes",
  "version": 1,
  "routes": [ { ...маршрут..., ...маршрут... } ]
}
```

Допустим также «голый» массив маршрутов: `[ {...}, {...} ]`.

## Структура маршрута

| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| `id` | строка | да | Уникальный идентификатор (латиница/цифры). Совпадение id перезаписывает маршрут |
| `name` | строка | да | Название, например «Дом — Работа» |
| `kind` | `bus` / `train` | нет | Вид транспорта. Если не задан — определяется по названию (слова «электричка», «поезд», «РЖД», «сапсан» → train) |
| `price` | число | нет | Стоимость проезда в рублях |
| `updated` | `ГГГГ-ММ-ДД` | нет | Дата актуальности данных (показывается в списке маршрутов) |
| `note` | строка | нет | Примечание под переключателем направления |
| `dirs` | массив | да | Направления (обычно 2: туда и обратно) |
| `dirs[].title` | строка | да | Название направления |
| `dirs[].flights` | массив | да | Рейсы |
| `flights[].t` | `ЧЧ:ММ` | да | Время отправления (для поездов — прибытия на станцию) |
| `flights[].r` | строка | да | Номер + название, например `533 Кипень — Гатчина` или `6830 Гатчина — СПб` |
| `flights[].d` | число | нет | Минуты в пути; тогда показывается время прибытия |
| `flights[].w` | `true` | нет | Только будни: рейс скрывается в выходные и праздничные дни |

Поля `builtin` задавать не нужно — импортированные маршруты всегда пользовательские.

## Пример одной строки из текстового формата

При добавлении маршрута вручную каждая строка расписания разбирается так:

```
07:15 518 Терволово — Гатчина 6 мин будни
│     │    └─ название рейса   └─ в пути └─ только по будням
│     └─ номер линии
└─ время
```

## Как подготовить файл из Яндекс Расписаний /Cutters

1. Откройте страницу расписания на rasp.yandex.ru.
2. Вручную соберите рейсы в виде строк (формат выше) — или сохраните страницу как CSV/JSON и преобразуйте по шаблону `template-route.json`.
3. Сохраните файл с расширением `.json` рядом с остальными шаблонами.
4. Импортируйте в приложении.

Готовые примеры: `template-electric.json` (электрички), `template-bus.json` (автобусы), `template-route.json` (пустой каркас).
